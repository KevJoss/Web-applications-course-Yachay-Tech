Web Applications

This course is a survey of technologies and techniques for building internet applications. It covers the fundamentals of HTTP, HTML, CSS, JavaScript, and server-side programming. It also covers topics such as security and accessibility.

Instructor: Francisco Hidrobo PhD.

Course content

The course content includes:

  • Introduction to Web Applications
  • HTTP and HTML
  • CSS and JavaScript
  • Server-side programming
  • Security
  • Accessibility

My top interests of the programs are:

  1. Frameworks of JavaScript (React, Angular, Vue.js)
  2. How to deploy web pages
  3. Modern tools and technologies

Machine Learning

This course is an introduction to machine learning. It covers the fundamentals of machine learning, including supervised learning, unsupervised learning, and reinforcement learning. It also covers topics such as model evaluation, model selection, and model deployment.

Instructor: Juan Pablo Astudillo PhD.

Course content

The course content includes:

  • Introduction to Machine Learning
  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning
  • Model Evaluation
  • Model Selection
  • Model Deployment

My top interests of the programs are:

  1. Algorithms of classification and regression
  2. How it works and deploy federated learning
  3. Efficiency of the solutions provied by ML algorithms
